# AI Web Scraper 🚀

An intelligent AI-powered web scraping application built using Python, Selenium, BeautifulSoup, Flask, and LLM integration. This project allows users to scrape website content, clean DOM data, and extract meaningful information using AI prompts.



## ✨ Features

* 🌐 Scrape dynamic and static websites
* 🤖 AI-powered content extraction
* ⚡ Selenium browser automation
* 🧹 DOM cleaning and preprocessing
* 📄 Structured data parsing
* 🔒 Rate limiting & ethical scraping concepts
* 🎯 Prompt-based information extraction
* 🖥 Simple and responsive UI
* 🐍 Built completely with Python

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/techwithtim/AI-Web-Scraper.git
cd AI-Web-Scraper
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Install ChromeDriver

Download ChromeDriver compatible with your Chrome version:

[ChromeDriver Download](https://chromedriver.chromium.org/downloads?utm_source=chatgpt.com)

Place it in your project directory or system PATH.

---

# ▶️ Run the Project

```bash
python app.py
```

Now open:

```bash
http://127.0.0.1:5000
```

 🧠 How It Works

```text
User URL
   ↓
Selenium Scrapes Website
   ↓
BeautifulSoup Parses HTML
   ↓
DOM Content Cleaning
   ↓
AI/LLM Processes Data
   ↓
Structured Output Returned
```



 📸 Core Functionalities

 ✅ Dynamic Website Scraping

 ✅ AI Content Extraction
